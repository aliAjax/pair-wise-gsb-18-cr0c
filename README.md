# hxwl-04 根管分离器械处置台

在原根管看板上补全的「根管内分离（折断）器械处置台」：按牙位记录根管、距根尖距离、分离器械与处置方案，覆盖封药/充填锁定、显微会诊排期、冻结返工与版本留痕。

## 技术栈

React + Vite + TypeScript + CSS（不增加任何依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 分层结构

- `src/domain/` 领域层，独立于界面
  - `types.ts` 数据模型：牙位记录、版本（代次）、流水、显微预约
  - `rules.ts` 纯函数校验与规则（R1–R5、冲突汇总、一致性检查）
  - `seed.ts` 常量与示例数据
- `src/state/store.ts` 状态层：`useSyncExternalStore` + localStorage 持久化，所有写操作先过校验
- `src/ui/` 界面层：表单、记录卡、显微台看板、冲突清单
- `src/App.tsx` 组装

## 业务规则

| 编号 | 规则 |
| --- | --- |
| R1 | 超出根尖，或距根尖超过 3mm，转显微会诊；未预约时进入冲突清单 |
| R2 | 封药或充填后禁止补记（流水追加与字段编辑均锁定），阶段单向推进 |
| R3 | 同一患者同一时段只能占用一个显微台 |
| R4 | 改期先释放原时段（原子操作：释放与新预约要么都成功要么都不做） |
| R5 | 处置完成冻结原记录；返工必须填写原因，生成新版本并保留旧版本取值 |

## 一致性

状态实时写入 localStorage，刷新后牙位、处置、预约、版本保持一致；侧栏与页脚提供结构一致性核对，冲突清单固定列出 **牙位 / 根管 / 距离 / 时段 / 命中规则**。

可在侧栏「重置为示例数据」恢复内置病例（含封药锁定、已冻结返工、超出根尖待会诊、同一时段双台冲突等场景）。
