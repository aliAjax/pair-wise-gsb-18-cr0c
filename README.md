# hxwl-04 牙科根管治疗 · 分离器械处置台

按牙位记录根管、距根尖距离、器械和方案，覆盖封药/充填锁定、显微会诊转诊、显微台预约与版本化返工。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 分层结构

- `src/domain/types.ts` — 领域数据：牙位记录、根管处置条目、显微台预约、冲突
- `src/domain/rules.ts` — 校验规则（纯函数）：锁定、转诊、占台、冻结、返工
- `src/domain/store.ts` — 状态动作与 localStorage 持久化、示例数据
- `src/App.tsx` — 界面：指标、筛选、录入、预约、冲突列表

## 处置规则

- 牙位记录根管、距根尖距离（负值表示超出根尖）、器械和方案
- 封药或充填后禁止补记
- 超出根尖或距根尖超过 3mm 必须转显微会诊
- 同一患者同一时段只能占一个显微台；改期先释放原时段
- 处置完成冻结原记录；返工生成带原因的新版本并保留旧值
- 冲突列出牙位、根管、距离、时段和规则
- localStorage 持久化，刷新后牙位、处置、预约和版本一致
